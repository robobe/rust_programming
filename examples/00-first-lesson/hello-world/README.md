# Hello World Cargo application

From the repository root, run:

```bash
cargo fmt --manifest-path examples/00-first-lesson/hello-world/Cargo.toml
cargo run --manifest-path examples/00-first-lesson/hello-world/Cargo.toml
cargo build --manifest-path examples/00-first-lesson/hello-world/Cargo.toml --release
```

Expected output:

```text
Hello, Rust!
```
