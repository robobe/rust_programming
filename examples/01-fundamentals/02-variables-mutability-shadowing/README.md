# Variables, mutability, and shadowing

Prerequisites: stable Rust and Module 1 Topics 1–2. No external crates are
required. Run these exact commands from the repository root. Rust runs directly;
the course `.venv` is used for documentation tooling.

```bash
rustc examples/01-fundamentals/02-variables-mutability-shadowing/main.rs -o /tmp/rust-fundamentals-2
/tmp/rust-fundamentals-2
```

Expected output:

```text
attempts: 3, limit: 10
```

The program includes assertions checking its demonstrated behavior.
The demo uses fixed, small values and no user input.
