# Conditions and pattern basics

Prerequisites: stable Rust and Module 1 Topics 1–6. No external crates are
required. Run these exact commands from the repository root. Rust runs directly;
the course `.venv` is used for documentation tooling.

```bash
rustc examples/01-fundamentals/06-conditions-and-patterns/main.rs -o /tmp/rust-fundamentals-6
/tmp/rust-fundamentals-6
```

Expected output:

```text
if: nonempty, match: multiple
```

The program includes assertions checking its demonstrated behavior.
Patterns cover integers and a wildcard. Enum patterns and Option are taught in Module 3.
