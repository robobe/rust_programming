# Fundamentals overview

Prerequisite: stable Rust installed in Module 0. No external crates are needed.
Run from the repository root; Rust runs directly, while the course `.venv`
is used for documentation tooling.

```bash
rustc examples/01-fundamentals/01-fundamentals-overview/main.rs -o /tmp/rust-fundamentals-intro
/tmp/rust-fundamentals-intro
```

Expected output:

```text
Hello, fundamentals!
```

This demo only prints a fixed greeting; it accepts no input.
