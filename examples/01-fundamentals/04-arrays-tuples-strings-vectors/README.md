# Arrays, tuples, strings, and vectors

Prerequisites: stable Rust and Module 1 Topics 1–4. No external crates are
required. Run these exact commands from the repository root. Rust runs directly;
the course `.venv` is used for documentation tooling.

```bash
rustc examples/01-fundamentals/04-arrays-tuples-strings-vectors/main.rs -o /tmp/rust-fundamentals-4
/tmp/rust-fundamentals-4
```

Expected output:

```text
count: 3, total: 12, values: [3, -1, 8, 2]
Hello, Rust
```

The program includes assertions checking its demonstrated behavior.
Indexes are fixed and valid. Detailed borrowing and UTF-8 slicing rules follow in Module 2.
