# Rust Programming: From Zero to Useful

Learn Rust from first principles to a small command-line application.

## Course target

By the end, you will be able to write, test, and package small Rust programs
with confidence.

## Who it is for

This course is for programmers who are new to Rust. You should be comfortable
with a terminal and basic programming ideas such as variables, functions, and
conditionals. Install the stable Rust toolchain with `rustup` before starting.

Start with [Module 0: First lesson](modules/00-first-lesson/index.md), then use
the [roadmap](roadmap.md) and [syllabus](syllabus.md) to plan the track.
