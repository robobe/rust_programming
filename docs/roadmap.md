# Roadmap

## Final goal

Build a tested command-line task tracker while learning Rust's ownership model,
types, error handling, and project tooling.

| Milestone | Modules | Outcome |
| --- | --- | --- |
| Foundation | 0–2 | Compile Rust, use core types, and understand ownership. |
| Application | 3–6 | Model data, use traits, handle errors, test projects, and apply Rust software design principles. |
| Capstone | 7 | Build and test a persistent command-line task tracker. |
| Advanced | 8–9 | Use closures, advanced lifetimes, and smart pointers. |
| Concurrent programs | 10–11 | Build threaded and async applications. |
| Systems practice | 12–13 | Measure performance and define safe unsafe/FFI boundaries. |

## Recommended sequence

1. Start with Module 0 and compile every example locally.
2. Learn basic types and collections in Module 1, then ownership and borrowing in Module 2.
3. Learn structs and traits before advanced lifetime and shared-ownership patterns.
4. Complete Modules 3–6 before the Module 7 capstone; apply Module 6 SOLID, composition, and testable design guidance in the project.
5. Continue to Modules 8–13 using the prerequisites in the [syllabus](syllabus.md).

Modules 0–1 are available. Module 2 Topics 1–7 are published, while Topic 8 and
Module 3 Topics 1–2 are published; the remaining Module 3 topics and Modules 4–13
are planned. Module 0 packaging, workspace, and embedded
extensions are optional for the main learning path.
