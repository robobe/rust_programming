# Roadmap

## Final goal

Build a tested command-line task tracker while learning Rust's ownership model,
types, error handling, and project tooling.

| Milestone | Modules | Outcome |
| --- | --- | --- |
| Foundation | 0–2 | Compile Rust, use core types, and understand ownership. |
| Application | 3–4 | Handle errors and organize code into a Cargo project. |
| Capstone | 5+ | Build and test a useful command-line task tracker. |

## Recommended sequence

1. Start with Module 0 and compile every example locally.
2. Learn ownership before borrowing, collections, and error handling.
3. Integrate each concept into the capstone only after the small example works.
