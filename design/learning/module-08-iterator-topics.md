# Module 8 iterator topics

Date: 2026-11-08

Status: Accepted

Make later iterator coverage explicit and connect the introductory range lesson
to that planned learning path.

## Key decisions

- Keep Module 8 planned, with Modules 2–5 as prerequisites.
- Order its topics from closures and laziness through adapters, consumers,
  ownership, and custom iterators.
- Name `map`, `filter`, `take`, `skip`, `enumerate`, `sum`, `count`, and
  `collect` explicitly. Explain that these are iterator methods usable on ranges.
- Add a forward reference in Topic 1.7 without expanding its introductory scope.
